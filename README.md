# Анализ рынка труда Санкт-Петербурга

## Обзор

В рамках проекта проведен комплексный анализ рынка труда Санкт-Петербурга с использованием экономических и статистических методов.

Исследование охватывает демографические факторы, состояние рабочей силы, занятость и безработицу, профессионально-отраслевую структуру занятости, уровень заработной платы и основные проблемы регионального рынка труда.

## Цель

Цель проекта — выявить ключевые тенденции развития рынка труда Санкт-Петербурга, определить факторы, влияющие на спрос и предложение рабочей силы, а также сравнить положение региона с другими субъектами Северо-Западного федерального округа.

## Методы

- сбор и обработка статистических данных
- анализ демографических показателей
- анализ динамики занятости и безработицы
- изучение государственных программ в сфере занятости
- межрегиональное сравнение показателей
- визуализация статистических данных
- SWOT-анализ рынка труда

## Инструменты

- Excel
- Статистический анализ
- Сравнительный анализ
- Визуализация данных
